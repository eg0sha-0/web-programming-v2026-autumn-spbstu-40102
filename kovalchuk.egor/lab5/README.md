# Лабораторная работа 5

## Задание

Вариант 40. Ковальчук Егор, `kovalchuk.egor`.

Реализовать на React компонент «Избранное» для книжного интернет-магазина.
Карточка каждой книги содержит обложку, название, рейтинг, описание и цену.
Кнопка «Добавить в избранное» добавляет книгу в отдельную подборку и меняет цвет
или иконку. В компоненте «Избранное» можно удалять книги. Состояние сохраняется
в localStorage и восстанавливается после перезагрузки страницы. Рядом с иконкой
избранного отображается количество выбранных книг.

## Реализация

Приложение написано на JavaScript и React, локальная сборка — Vite.

- `index.html` — единственный HTML-файл, контейнер React и подключение entry.
- `src/main.jsx` — запуск React и подключение CSS.
- `src/App.jsx` — состояние избранного, счётчик и localStorage.
- `src/books.js` — локальный каталог из шести книг.
- `src/components/BookCard.jsx` — карточка книги с переключателем избранного.
- `src/components/Favorites.jsx` — отдельный компонент подборки и удаление.
- `src/components/HeartIcon.jsx` — общая иконка сердца.
- `src/styles.css` — адаптивный интерфейс и состояния элементов.
- `assets/` — шесть оригинальных векторных обложек SVG.
- `vite.config.js` — автоматическое преобразование JSX для локальной сборки.

Избранное хранится как массив строковых ID под ключом
`kovalchuk.egor.lab5.favorites`. При старте ленивый инициализатор `useState`
читает localStorage; повторные и неизвестные ID отбрасываются. Повреждённый JSON
обрабатывается сообщением и пустой подборкой. При ошибке записи показывается
сообщение, а текущая подборка остаётся без изменений.

Добавление и удаление используют общее состояние: карточки, подборка и счётчик
обновляются одновременно. Повторный клик по выбранной книге удаляет её из
избранного. Дубликаты не создаются. Для кнопок используется `aria-pressed`,
выбранное состояние показывает заполненное сердце и зелёный фон. Ссылка
избранного в шапке ведёт к подборке. Предусмотрены пустое состояние, сообщения
об операциях, клавиатурный фокус и адаптация к узким экранам.

Публичный DOM-контракт: корневой `main[data-testid="app"]`, `book-card`,
`favorite-add`, `favorites-list`, `favorites-count`, `favorite-item`. Для
удаления дополнительно используется `favorite-remove`.

Каталог, описания и иллюстрации находятся внутри лабораторной. Внешние API, CDN
и удалённые изображения не используются. Цены и рейтинги — учебные данные.
Запуск приложения после установки зависимостей не требует интернета.

## Запуск

Для соответствия окружению курса используйте Node.js `24.19.0`, указанный в
корневом README курса. Откройте терминал в папке этой лабораторной:

```bash
cd kovalchuk.egor/lab5
npm install
npm run dev
```

Если VS Code уже открыт непосредственно в `lab5`, команду `cd` пропустите.
Перейдите по адресу, который Vite выведет в терминале, обычно
`http://127.0.0.1:5173`. Остановить сервер можно сочетанием Ctrl+C. В
PowerShell, если выполнение `npm.ps1` заблокировано, используйте `npm.cmd`
вместо `npm`. В Git Bash работают команды выше.

Проверка сборки и её просмотр:

```bash
npm run build
npm run preview
```

Для этой React-лабораторной нужен Vite: Live Server и открытие HTML через
`file://` не преобразуют JSX и импорты npm-пакетов.

Проверка вручную: добавьте две разные книги, проверьте счётчик и выделение
кнопок; перезагрузите страницу. Удалите одну книгу из компонента «Избранное» и
проверьте кнопку в каталоге. Повторным нажатием выбранной кнопки удалите
последнюю книгу. После перезагрузки подборка должна оставаться пустой.

Проверки перед сдачей из корня репозитория курса:

```bash
npm run format -- kovalchuk.egor/lab5
npm run format:check -- kovalchuk.egor/lab5
npm run lint:js -- kovalchuk.egor/lab5
npm run lint:css -- "kovalchuk.egor/lab5/**/*.css"
npm run lint:html -- "kovalchuk.egor/lab5/**/*.html"
```

Название PR: `[TASK-5] variant_40 kovalchuk.egor`. В PR должны входить только
файлы `kovalchuk.egor/lab5`. Каталоги `node_modules`, `dist` и lock-файлы не
добавляйте: локальный `.gitignore` исключает создаваемые npm файлы. GitHub CI
запускается при открытии PR.
