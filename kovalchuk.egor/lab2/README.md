# Лабораторная работа 2

## Задание

Реализовать функцию, которая принимает дату и возвращает строку с описанием
того, сколько времени прошло с этой даты (например, «5 минут назад», «2 часа
назад», «3 дня назад» и т.д.).

## Реализация

Функция `timeAgo(date, now)` экспортируется именованно как ES module. Она
принимает дату в виде `Date`, timestamp (число миллисекунд) или строки,
пригодной для `new Date()`, а также необязательный второй аргумент `now` — точку
отсчёта (по умолчанию текущее время), что позволяет тестировать функцию без
побочных эффектов и не зависеть от реального времени выполнения.

Разница между `now` и переданной датой переводится в секунды и сопоставляется с
одной из единиц измерения (секунды, минуты, часы, дни, месяцы, годы). Единица
выбирается по возрастанию, а значение округляется вниз. Для интервалов меньше 5
секунд, а также для дат из будущего возвращается «только что». Отдельная функция
`pluralize` подбирает правильную форму слова по правилам русского языка (1
минута / 2 минуты / 5 минут) на основе остатков от деления на 10 и 100.

Функция синхронна, не изменяет входные данные и не использует `Promise`.

## Запуск

Функция экспортируется из `solution.js` как ES module и может быть импортирована
и вызвана напрямую:

```js
import {timeAgo} from './solution.js';

timeAgo(new Date(Date.now() - 5 * 60 * 1000)); // "5 минут назад"
```
