# Лабораторная работа 3

## Задание

Реализуйте функцию `moveZerosToEnd(arr)`, которая перемещает все нули в конец
массива, сохраняя порядок остальных элементов.

## Реализация

Функция `moveZerosToEnd(arr)` экспортируется именованно как ES module. Она
проходит по входному массиву один раз: ненулевые элементы добавляются в
результирующий массив в исходном порядке, а число встреченных нулей
подсчитывается отдельно. После основного прохода в конец результирующего массива
дописывается ровно столько нулей, сколько было найдено.

Сравнение с нулём выполняется строго (`item === 0`), поэтому переносятся только
числовые нули; строки, `null`, `undefined`, `false` и другие ложные значения не
считаются нулями и остаются на своих местах.

Функция не изменяет входной массив — возвращается новый массив с исходным `arr`,
оставленным без изменений.

## Запуск

Функция экспортируется из `solution.js` как ES module и может быть импортирована
и вызвана напрямую:

```js
import {moveZerosToEnd} from './solution.js';

moveZerosToEnd([0, 1, 0, 3, 12]); // [1, 3, 12, 0, 0]
```
