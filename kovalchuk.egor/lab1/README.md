# Лабораторная работа 1

## Задание

Свёрстать флаг Бангладеша. Красный круг в центре флага реализован с помощью
`position: absolute` и размещён точно по центру родительского блока так, чтобы
оставаться отцентрированным при изменении размеров флага. Размеры флага выбраны
произвольно.

## Реализация

Страница состоит из блока `.flag`, играющего роль флага, и вложенного в него
`.flag__circle` — красного круга. Родительский блок `.flag` имеет
`position: relative`, а круг `.flag__circle` — `position: absolute` со
свойствами `top: 50%`, `left: 50%` и `transform: translate(-50%, -50%)`, что
обеспечивает точное центрирование независимо от размеров флага. Размеры круга и
флага заданы в относительных единицах (`%`, `aspect-ratio`), поэтому пропорции
сохраняются при масштабировании.

## Запуск

Открыть файл `index.html` в любом современном браузере — дополнительная сборка
не требуется.
