# Лабораторная работа 4

## Задание

Вариант 40. Ковальчук Егор, каталог `kovalchuk.egor`.

Создать класс путешествия с полями `id` (уникальный числовой номер),
`travelerName` (имя) и `visitedCountries` (массив строк). Реализовать методы
`addCountry(country)`, `removeCountry(country)` и геттер `visitedCount`.

Для массива путешествий реализовать пять операций:

1. Группировка по количеству посещённых стран.
2. Получение уникального списка посещённых стран.
3. Поиск путешествий, включающих заданную страну.
4. Группировка путешественников по странам.
5. Поиск путешественников, посетивших строго более N стран.

Создать интерфейс с карточками, формой создания путешествия (ID, имя), формами
добавления страны и кнопками добавления/удаления стран и путешествий. Все
изменения выполнять асинхронно через Promise и setTimeout, автоматически
обновлять интерфейс и сохранять список в localStorage с восстановлением после
перезагрузки страницы или повторного открытия вкладки.

## Реализация

- `model.js` — именованный экспорт класса `Travel` и пяти функций коллекции:
  `groupTravelsByCountryCount`, `getUniqueCountries`, `findTravelsByCountry`,
  `groupTravelersByCountry`, `findTravelsAboveCountryCount`.
- `main.js` — создание DOM, обработчики форм, асинхронные изменения, хранение
  данных и отображение результатов всех пяти операций.
- `index.html` — семантическая разметка и подключение ES-модуля.
- `styles.css` — адаптивное оформление, состояния кнопок и клавиатурного фокуса.

Конструктор: `new Travel(id, travelerName, visitedCountries = [])`. Входной
массив стран копируется. Повторы стран не добавляются. Названия и имена
очищаются от пробелов по краям; страны сравниваются точно, с учётом регистра.
Удаление отсутствующей страны не меняет данные. Уникальность ID проверяется при
добавлении путешествия в коллекцию и при восстановлении сохранённого списка.

Группировки возвращают `Map`: количество стран → массив объектов `Travel` и
страна → массив объектов `Travel` соответственно. Остальные функции возвращают
массивы. Функции коллекции синхронны и не изменяют исходный массив и его
объекты. Уникальные страны сохраняют порядок первого появления. Пустой входной
массив даёт пустую группировку или пустой массив.

Все четыре операции изменения проходят через `changeTravels`: ожидание
`new Promise` с `setTimeout` на 250 мс, изменение копии состояния, запись в
localStorage, затем обновление карточек и обзора без перезагрузки страницы. На
время операции кнопки блокируются. При ошибке показывается сообщение. Данные
хранятся под ключом `kovalchuk.egor.lab4.travels`. При загрузке JSON
преобразуется обратно в экземпляры `Travel`, поэтому методы и геттер работают.
Некорректный JSON обрабатывается сообщением и открытием пустого списка.

Обязательные селекторы: `[data-testid="entity-list"]`,
`form[data-testid="entity-form"]`, `[data-testid="entity-card"]`,
`[data-testid="delete-entity"]`. Основные поля формы имеют имена `id` и
`travelerName`. Пользовательские строки вставляются через `textContent`. Внешних
ресурсов, библиотек и сетевых API нет.

## Запуск

Из корня репозитория курса запустите статический HTTP-сервер, например:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/kovalchuk.egor/lab4/`. Также можно использовать
расширение Live Server в VS Code. Страницу нужно открывать через HTTP-сервер:
подключённые ES-модули требуют HTTP, а не file://. Установка npm-зависимостей
внутри lab4 не требуется.

Проверка вручную: добавьте два путешествия с разными ID, добавьте им страны,
проверьте обе группировки, уникальный список, поиск по стране и порог N.
Попробуйте повторный ID, повторную страну и пустые поля. Перезагрузите страницу,
удалите страну и путешествие, затем ещё раз перезагрузите: изменения
сохраняются.

Перед сдачей перенесите эту папку в `kovalchuk.egor/lab4` своего fork, выполните
проверки из корня репозитория курса:

```bash
npm run format -- kovalchuk.egor/lab4
npm run format:check -- kovalchuk.egor/lab4
npm run lint:js -- kovalchuk.egor/lab4
npm run lint:css -- "kovalchuk.egor/lab4/**/*.css"
npm run lint:html -- "kovalchuk.egor/lab4/**/*.html"
```

Название PR: `[TASK-4] variant_40 kovalchuk.egor`. В PR должна изменяться только
эта лабораторная. Официальный CI запускается после открытия PR.
