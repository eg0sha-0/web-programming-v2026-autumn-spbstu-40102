# Gadget Hub API

Базовый адрес: `http://127.0.0.1:8080/api`. Фронтенд обращается к `/api` через
proxy Vite. Формат запроса и ответа — JSON. Авторизация — HttpOnly cookie
`gh_session`, путь `/api`, SameSite=Lax, срок восемь часов.

| Метод | Путь        | Доступ      | Ответ / назначение                                |
| ----- | ----------- | ----------- | ------------------------------------------------- |
| GET   | `/health`   | Открытый    | `{ "ok": true }`                                  |
| GET   | `/session`  | Открытый    | `{ "user": null }` или объект пользователя        |
| POST  | `/login`    | Открытый    | Проверка логина/пароля, установка cookie          |
| POST  | `/logout`   | Открытый    | Завершение сессии и удаление cookie               |
| GET   | `/featured` | Открытый    | Товары для каруселей главной                      |
| GET   | `/goods`    | После входа | `{ "goods": [...] }`, полный каталог              |
| GET   | `/orders`   | После входа | `{ "orders": [...] }`, новые заказы первыми       |
| POST  | `/orders`   | После входа | Создание заказа, ответ 201 с `{ "order": {...} }` |

## Вход

```json
{"login": "egor", "password": "GadgetHub2026!"}
```

Успех: 200, `{ "user": { "id": "demo", "username": "egor" } }`. Пустые
поля: 400. Неверные данные: 401.

## Оформление заказа

```json
{
  "requestId": "c274742c-5310-46cd-b49d-bd4659699efb",
  "items": [{"id": 101, "quantity": 1}],
  "customer": {
    "phone": "+7 (999) 123-45-67",
    "email": "",
    "delivery": "pickup",
    "address": "",
    "payment": "cash",
    "packaging": false
  }
}
```

- `requestId` — строка длиной 10–100 символов из букв, цифр, `_` и `-`.
  Повторный запрос с тем же ID и пользователем возвращает существующий заказ.
- `items` — непустой массив уникальных существующих товаров.
- `quantity` — целое число от 1 до 99.
- `phone` — обязательный номер; разрешены цифры, пробелы, скобки, дефисы и
  начальный `+`, необходимо минимум семь цифр.
- `email` — необязательный, непустое значение проверяется как адрес почты.
- `delivery` — `pickup` или `delivery`; для доставки требуется непустой адрес.
- `payment` — `card` или `cash`.
- `packaging` — boolean.

В ответе заказ содержит ID, ISO-дату, пользователя, снимок товаров с ценами,
данные покупателя, сумму `total` и количество единиц `quantity`. Цена и итог,
присланные клиентом, не используются: сервер пересчитывает их.

## Ошибки

```json
{
  "message": "Проверьте данные заказа.",
  "errors": {"phone": "Введите корректный номер телефона."}
}
```

400 — неверные поля, товары или JSON. 401 — нет действующей сессии. 404 —
неизвестный метод API. 413 — слишком большой запрос. 500 — ошибка чтения или
сохранения данных; детали файловой системы клиенту не отправляются.

Сервер проверяет авторизацию независимо от клиентских маршрутов. История
возвращает только заказы текущего пользователя.
